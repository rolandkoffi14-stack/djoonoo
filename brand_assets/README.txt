# djoonoo — Brand Asset Production Pack

Palette
- Terracotta: #C1652D
- Brun très foncé: #2B2119
- Blanc cassé chaud: #FAF6F1

Typography
- Wordmark: Montserrat Bold, lowercase `djoonoo`. The production SVGs embed the letterform geometry as vector outlines so the logo does not depend on a locally installed font.

The isotype geometry is rebuilt as clean vector paths from the supplied logo3.png/logo4.png references. Gradients, shadows and background photography from the prototypes are intentionally removed so the production assets use only the requested brand palette.

Raster standards
- Horizontal transparent logos: 520×192, 1040×384, 1560×576 (@1x/@2x/@3x).
- Squircle icons: 512×512, 1024×1024, 1536×1536 (@1x/@2x/@3x).
- Background horizontal logos: 1560×576.
- Favicon: multi-size ICO (16/32/48), transparent.
- Apple touch icon: 180×180.
- Android Chrome: 192×192 and 512×512.

Transparent PNGs retain alpha; background variants are opaque.
